# SimplyPaste

Печатает текст из буфера обмена посимвольно, эмулируя ввод с клавиатуры. Полезно там, где Ctrl+V не работает: RDP, VM-консоли, BIOS, защищённые поля.

## Установка

```bash
pip install -r requirements.txt
python main.py
```

> Требуются права администратора для глобального перехвата клавиш.

## Использование

1. Скопируй текст в буфер обмена
2. Переключись в нужное окно
3. Нажми горячую клавишу (по умолчанию `F9`)

Настройки (клавиша, задержка) сохраняются автоматически в `config.json`.
